One line, at most 200 characters, that makes a meeting-that-should-have-been-an-email funny. The entry:

> The meeting's only outcome was a second meeting to discuss why the first meeting should have been an email.

## Run it

```sh
python3 main.py
```

`main.py` (pure standard library) writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), self-checks it is 1–200 characters, a single line, and not only white space, then re-reads the file to verify the bytes. Two runs produce byte-identical output.
